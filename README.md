# Сайт факультету гуманітарних наук НаУКМА

Я обрала факультет гуманітарних наук (ФГН), бо в нього немає власного сайту.
Уся інформація про факультет - це одна сторінка на сайті НаУКМА та окремі сторінки кафедр у різних розділах.

Інформація розкидана: опис програм є на сайті вступу, дисципліни - у каталозі ECTS,
викладачі - на сторінках кафедр. Частина даних застаріла: в описі факультету згадано шість кафедр і чотири напрями, хоча зараз їх більше.
Деяких даних немає зовсім: для бакалаврату «Археологія» немає списку дисциплін, а в багатьох викладачів не вказано науковий ступінь, тому це довелось вигадувати.
Тому вступнику доводиться шукати інформацію на кількох сайтах одразу. Цей сайт збирає її в одному місці.


## Запуск

```bash
python manage.py migrate
python manage.py loaddata data.json
python manage.py runserver
```
